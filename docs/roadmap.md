# Roadmap — gates to a trainable frontier-scale model

Priority: **Track A (GENESIS core + genesis-fin)**. Track B keeps pretraining as a learning track; GENESIS-1B-KO and the 10T experiment stay long-term goals.
Each gate demands test evidence and measurement; no dates or expense guarantees.

## Mid-point check (2026-11-08)

- **Done since 11-03:** A2 baseline and first QLoRA (85.3% -> 84.0%, no gain: the errors were the model's own arithmetic); **polarbear** tool layer (model writes the formula, `genesis.tools` calculates) took the same 544 items to 98.7%, so **fin-v1 is frozen** as base Qwen3-4B + polarbear (no more finance GPU training). Polarbear was then checked on code-generated sets: everyday 420 (92.9 -> 97.9%), hard 360 (49.2 -> 66.9-83.1% with opt-in flags), multi-step 240 (78.3 -> 92.1%), no-calculation guard 240 (85.8 -> 81.2%, fixed by `--route`: 86.2%). Options that measured no gain were removed (PR #69).
- **Weak spot:** every polarbear number is one run on a set generated by our own code; differences of a few items are noise, and tuning hints to our own sets is circular.
- **Next, in order:** (1) ~~repeat the key comparisons on freshly generated sets and report a range~~ (done, seeds 1-5); (2) ~~**public benchmarks not written by us** (KMMLU, Korean GSM8K full)~~ (done: no harm on KMMLU, polarbear is lower than baseline on GSM8K-ko); (3) ~~served evaluation = local evaluation~~ (done 2026-11-11, one set: 86.7% local vs 86.2% served, 1 of 240 verdicts differs); (3b) ~~decide what to do about the GSM8K-ko result~~ (decided 2026-11-11: no new option; polarbear is scoped to structured calculation questions where the values are given, called where the app knows it is a calculation; reopen only if the 4-a demo shows the same failure repeatedly, with a pre-set keep/remove rule; docs/12 last section); (4) A3 harder finance tasks (numbers in filing text = verification against source). No new options unless a measured failure on an external set calls for one.
- **Not moving:** Track B Gate 2 (no H100/A100 budget yet), Gate 1 legal review (before any commercial release).

## Track A — GENESIS core + genesis-fin (priority, practical track)
An open base model + the GENESIS core (see [11_core_ko.md](11_core_ko.md)) + domain adapters. First domain: **Korean** corporate finance (OpenDART filings) with LoRA/QLoRA; publish accuracy, cost and speed. Japan is an optional later extension.
