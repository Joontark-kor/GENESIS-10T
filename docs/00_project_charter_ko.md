# GENESIS-10T | 프로젝트 헌장 (2026-10-21)

## 북극성 목표

합법적으로 수집·사용할 수 있는 데이터에서 시작해, 독립적인 모델 구조와 학습 시스템을 설계하고, 최종적으로 총 10조(10T) 파라미터 규모의 희소 MoE 언어모델 사전학습을 **실제로 검증 가능한 형태로 시도**한다.

- '세계 최대'는 아직 확보한 지위가 아닌 **야심 찬 목표**다.
- 공개하지 않은 상용 모델은 비교하기 어려우므로, 총 파라미터/활성 파라미터/실제 학습 여부/날짜를 구분해 기록한다.
- 파라미터 규모는 목표 가운데 하나일 뿐, 실사용 품질·안전성·비용은 독립적인 합격 기준으로 본다.
- 10T는 한 대의 컴퓨터가 아니라 다수의 가속기, 고속 상호연결, 스토리지, 연구·엔지니어링 팀, 상당한 자금을 요구한다.

## 개발 전략

실험용 모델을 '최종 제품'으로 생각하지 않는다. 초대형 모델을 구현하기 위한 각 요소의 정확성·안정성·성능을 확인하는 **테스트 장치**로 사용한다.

1. **실행 가능한 최소 엔진**: 현재 구현. 데이터 정제/토큰화/Transformer/MoE/학습/생성 + 자동 테스트.
2. **효율적인 단일 노드**: 학습기 개선, 정교한 토크나이저, 데이터 거버넌스, 벤치마크.
3. **다중 GPU**: 분산 병렬화, 장애 복구, GPU 활용률 측정.
4. **대규모 모델 연구**: 모델/데이터/연산량에 대한 실측 확장법칙과 효율성을 비교.
5. **10T 학습**: 연구 자금/인프라/학습 데이터/독립 평가체계를 갖춘 다음 실행.

## 지금 사용 가능한 것과 부족한 것

사용 가능: 소규모 CPU/GPU 디버깅 모델, 샘플 데이터, 교육/연구용 스타터 코드.

아직 없음: 실제 10T 가중치, 학습된 고성능 언어 능력, 다중 노드 전문화 병렬화, 대규모 적법성 검증 데이터셋, 벤치마크 결과, 연구팀·대규모 GPU 예산.

## 통과 없이는 확장하지 않는 기준

- 코드 정확성: 숫자 안정성, 단위 테스트, 회귀 테스트.
- 데이터: 권리, 개인정보, 중복, 평가셋 오염, 품질.
- 연산: 처리량(tokens/s), GPU 메모리, 네트워크 병목.
- 복구: 학습 중 중단 후 검증된 재시작.
- 모델: 독립 평가 점수, 환각률, 장문맥, 악용 위험.
